NOAA ROB Pipeline — Compact Overview

Ringkasan singkat proyek ini: sebuah pipeline untuk memproses data NOAA, mengekstrak fitur, melatih model prediksi tinggi air, dan menyediakan dashboard pemantauan.

Struktur singkat:
- `frontend/` — aplikasi UI (Vite + TS)
- `noaa-rob-pipeline/` — pipeline Airflow, backend, DAGs, model dan skrip

Quick start:
1. Backend: lihat `noaa-rob-pipeline/backend/` untuk entry point dan requirements.
2. Frontend: jalankan `pnpm install` lalu `pnpm dev` di `frontend/`.
3. Infrastruktur: ada Dockerfile dan docker-compose untuk komponen utama.
