
NOAA ROB Pipeline — Tujuan, Setup, dan Cara Menjalankan

Tujuan
- Proyek ini mengumpulkan data NOAA (water level), memprosesnya (pembersihan, agregasi, quality checks), melatih model prediksi tinggi air, dan menyediakan API + dashboard untuk pemantauan.

Apa yang ada di repo
- `frontend/` — UI (Vite + React + Tailwind)
- `noaa-rob-pipeline/` — core pipeline: DAG Airflow, backend FastAPI, skrip, model, dan konfigurasi
- `noaa_rob_modelling_v5_2021_2026M5.ipynb` — notebook analisis dan eksperimen

Prerequisites
- Python 3.10+ (direkomendasikan), pip
- Node.js + pnpm (untuk frontend)
- Docker & docker-compose (opsional, untuk environment terkontainer)

Setup singkat (lokal)

Backend (virtualenv):

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
# source .venv/bin/activate
pip install -r noaa-rob-pipeline/backend/requirements.txt
```

Jalankan backend (development):

```bash
cd noaa-rob-pipeline/backend
python main.py
```

Frontend:

```bash
cd frontend
pnpm install
pnpm dev
```

Menjalankan seluruh stack dengan Docker (opsional):

```bash
docker-compose up --build
```

Lokasi penting
- DAG Airflow: `noaa-rob-pipeline/dags/`
- Backend entrypoint: `noaa-rob-pipeline/backend/main.py`
- Requirements backend: `noaa-rob-pipeline/backend/requirements.txt`
- Grafana dashboards: `noaa-rob-pipeline/grafana/`
- Model artifacts: `noaa-rob-pipeline/models/` (jangan commit ke git)

Catatan
- Pastikan `data/`, `logs/`, dan `models/` tidak ikut commit — sudah dicakup oleh `.gitignore`.
- Untuk modifikasi DAG atau deployment, periksa `docker-compose.yml` dan Dockerfile terkait.
