

NOAA ROB Pipeline — README Lengkap (Setup & Run)

Ringkasan
Proyek ini mengumpulkan data permukaan air (NOAA), membersihkan dan mengagregasi data, menjalankan quality checks, melatih model prediksi tinggi air, serta menyajikan API dan dashboard untuk pemantauan.

Struktur utama
- `frontend/` — React + Vite UI
- `noaa-rob-pipeline/` — core pipeline: Airflow DAGs, backend (FastAPI), skrip, model, konfigurasi
- `noaa_rob_modelling_v5_2021_2026M5.ipynb` — notebook analisis

Persyaratan (prerequisites)
- Git
- Python 3.10+ dan `pip`
- Node.js 16+ dan `pnpm` (atau npm/yarn)
- Docker & Docker Compose (direkomendasikan untuk menjalankan stack lengkap)

Langkah-langkah setup (dari awal)

1) Clone repository

```bash
git clone <repo-url>
cd "proj ipbd 2"
```

2) Menyiapkan backend (lokal, tanpa Docker)

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r noaa-rob-pipeline/backend/requirements.txt
```

macOS / Linux:

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r noaa-rob-pipeline/backend/requirements.txt
```

3) Konfigurasi environment variables (contoh `.env`)

Buat file `.env` di `noaa-rob-pipeline/backend/` dengan variabel contoh (sesuaikan nilai):

```
FASTAPI_HOST=0.0.0.0
FASTAPI_PORT=8000
DATABASE_URL=postgresql://user:pass@localhost:5432/noaa
KAFKA_BOOTSTRAP_SERVERS=localhost:9092
MODEL_PATH=./models/model.pkl
TELEGRAM_TOKEN=
```

4) Menjalankan backend (development)

```bash
cd noaa-rob-pipeline/backend
# aktifkan virtualenv jika belum
python main.py
```

Endpoint utama biasanya tersedia di `http://localhost:8000`.

5) Menjalankan frontend

```bash
cd frontend
pnpm install
pnpm dev
```

Default frontend berjalan di `http://localhost:5173`.

6) Menjalankan seluruh stack dengan Docker Compose (direkomendasikan untuk integrasi lokal)

```bash
docker-compose up --build
```

Periksa `docker-compose.yml` di root repo untuk daftar service (Postgres, Kafka, Zookeeper, Airflow, dsb.).

Komponen penting
- DAG Airflow: `noaa-rob-pipeline/dags/`
- Backend entrypoint: `noaa-rob-pipeline/backend/main.py`
- Backend requirements: `noaa-rob-pipeline/backend/requirements.txt`
- Grafana dashboards: `noaa-rob-pipeline/grafana/`
- Model artifacts: `noaa-rob-pipeline/models/` (JANGAN commit ke git)

Perintah cepat
- Jalankan backend: `python noaa-rob-pipeline/backend/main.py`
- Jalankan frontend: `pnpm --prefix frontend dev`
- Jalankan stack: `docker-compose up --build`

Troubleshooting singkat
- Jika backend gagal koneksi DB: pastikan `DATABASE_URL` benar dan Postgres berjalan.
- Jika frontend tidak muncul: pastikan dependencies terinstall (`pnpm install`) dan port tidak dipakai.
- Untuk masalah Airflow, periksa logs container Airflow jika menggunakan Docker.

Opsional — file contoh dan automatisasi
- Saya bisa buat `noaa-rob-pipeline/backend/.env.example` untuk mempermudah konfigurasi.
- Saya juga bisa menambahkan `Makefile` atau skrip PowerShell untuk perintah umum.

Butuh saya tambahkan `/.env.example` dan `Makefile` sekarang? Pilih: `env example`, `makefile`, `both`, atau `none`.
